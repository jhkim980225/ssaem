### 평가 CSV 한글 깨짐 수정 + 실사용 검증 (v0.12.1)
테이블 생성 후 라이브 e2e에서 잡힌 버그.
- **CSV 인코딩 강제 오류**: 파서가 `codepage: 949`를 무조건 걸어 **UTF-8 CSV의 한글이 전부 깨졌다**(`문제`→`ë¬¸ì `). 헤더 매칭까지 실패해 헤더 행이 "깨진 문항"으로 집계(skipped 부풀림)
  - 수정: xlsx(zip)는 바이트 그대로, **CSV는 직접 디코딩** — UTF-8로 읽히면 UTF-8, 아니면 euc-kr(cp949). BOM 제거
  - 헤더 판정 보강: 헤더 이름을 못 찾아도 첫 행 정답 칸이 1~4가 아니면 헤더로 간주(문항으로 오집계 방지)
- 회귀 테스트 추가: UTF-8 / BOM 붙은 UTF-8 / cp949 CSV 3종 (test-assessment 19→25)
- **실사용 검증**: 한글 CSV(BOM) 업로드 → 3문항 생성 → 학생 응시 → 서명 손글씨 → 제출 → 2/3 채점 → 1회 제한 잠금 → DB 정합(응답 3건·서명 8.7KB·IP) 전부 확인
- 최종: e2e 122 · matrix 174 · tenant 18 통과 (실패 0)

### 인증 상태 단일 스토어 — 페이지 이동 깜빡임 근본 제거 (v0.9.0)
