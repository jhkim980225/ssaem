### 자료 등록 경로 rate limit (v0.9.4)
`/api/upload`은 **전 라우트 중 유일하게 한도가 없었다**. 요청 1건이 15MB 파싱 + 청킹 + 임베딩을 돌리고, 스캔 PDF면 파일 전체를 비전 모델에 밀어넣는다.
- `upload:<uid>` 시간당 30회 — **본문을 읽기 전에** 막는다(15MB를 반복 버퍼링하지 않게)
- `ocr:<uid>` 시간당 10회 — 비전 호출은 업로드보다 좁게

### 인증 상태 단일 스토어 — 페이지 이동 깜빡임 근본 제거 (v0.9.0)
"로그인 후 페이지를 옮기면 헤더의 로그인 상태가 잠깐 풀려 보이고 본문이 비었다 그려진다"는 신고. 에이전트 3대로 인증 경로를 전수 조사해 **원인 3개를 코드로 특정**했다. 증상을 가린 게 아니라 상태가 사는 위치를 바꿨다.

**원인**
- **A. 헤더가 `ready`를 버림** — `SiteHeader`가 `useSession()`에서 `session`만 구조분해해 "조회 전"과 "비로그인"이 구분되지 않았다. 로그인한 사용자에게 `[로그인]` → `[]`(빈 내비) → 역할 메뉴로 **두 번** 바뀜
- **B. 세션이 컴포넌트 인스턴스별 상태** — `useSession`이 `{session:null, ready:false}`에서 출발하고 `getSession()`은 비동기라, `<Link>` 이동마다 "모르는 렌더"가 커밋된 뒤에야 채워졌다. `roleCache`는 **role만** 캐시하고 session에는 대응 캐시가 없었다. 이게 뿌리
- **E. 401을 `{profile:null}`과 같은 `null`로 뭉갬** — 서버는 구분해 응답하는데 클라가 상태코드를 안 봤다. 세션 만료가 **"강사 계정만 쓸 수 있어요"** 로 표시되고, `/login`에선 "강사 신규 가입자"로 오인돼 `/teacher`로 착지했다

배제한 것(코드 확인): full page reload 아님(`window.location.href=` 0건), Provider remount 아님(Provider 자체가 없었음), 헤더 remount 아님(root layout 소속), 내비 hydration 불일치 아님.

**해결** — `src/lib/auth-store.ts` 신설. 모듈 싱글턴 + `useSyncExternalStore`
- `status`를 `loading | signed-out | signed-in` **3종으로 명시** → `loading`에 비로그인 UI를 그리지 않는다
- 라우트 이동으로 초기화되지 않으므로 확정 후엔 **첫 렌더부터 동기로** 읽는다
- **uid가 바뀔 때만** role 재조회 — 토큰 갱신으로 세션 객체만 바뀌면 유지. 예전엔 `TOKEN_REFRESHED`마다 마운트된 모든 `useRole`이 `/api/profile`을 다시 불렀다
- 401 → `signOut()`, 200+`profile:null` → `role=null`로 구분
- `useGate` **시그니처 유지** → 보호 페이지 9개 무수정
- `RoleLoading` 전면 스피너 → 본문 스켈레톤. 헤더는 확정 전 고정폭 자리
- `lib/role.ts`는 순수 함수(`homeFor`·`roleFitsTab`)만 남김

**같이 고친 것**
- **`/join/<code>`가 `studentInviteCode`를 signup에 안 넘기던 버그** — 서버가 학원을 못 찾아 **기본 학원**으로 프로필을 만들었다. 학생의 `academy_id`와 실제 수강 강사의 학원이 어긋나 테넌트 경계가 깨졌다

- `GET profiles?select=name,role` — 같은 학원 전원 실명·uuid·역할 (미성년 학생 실명 명단)
- `GET messages?select=content` — 남의 질문·답변 원문

대응: `supabase/migrations/20260810000000_lock_client_rls.sql` — 클라이언트용 정책 전부 제거 + RLS 재확인. 서버 라우트는 전부 service_role(RLS 우회)이고 **클라이언트가 테이블을 직접 읽는 코드가 한 곳도 없어서**(`supabase` import는 전부 auth 용도) 기능 영향 0.
