# 학원 AI 튜터 — 서비스 소개

> 강사가 올린 문제·풀이 자료를 근거로, 학생이 24시간 질문하고 답을 받는 학원 전용 AI 조교.

---

## 한 줄 요약

**"우리 학원 강사가 가르치는 방식 그대로" 답하는 AI 조교.** 인터넷의 아무 정보가 아니라,
강사가 직접 올린 자료에서만 답을 찾고, 답변마다 어느 자료를 근거로 했는지 **출처**를 보여준다.

---

## 어떤 문제를 푸나

- 학생은 수업 끝나고 밤에 막히는데, 그때 물어볼 곳이 없다.
- 일반 AI(챗봇)는 그럴듯하게 답하지만 **우리 학원 교재·풀이법과 다르게** 답해 오히려 혼란을 준다.
- 강사는 같은 질문에 반복해서 답하느라 시간을 뺏긴다.

→ **강사 자료를 근거로 한 AI**가 1차로 답하고, 강사는 어떤 질문이 많은지·어디서 막히는지
데이터로 본다. 학생은 언제든 묻고, 강사는 자료만 관리하면 된다.

---

## 이용 흐름

```
원장이 학원 개설 → 강사 초대
   → 강사가 문제·풀이 자료 등록 (텍스트 붙여넣기 / PDF 업로드)
      → 학생 초대 (QR·링크) → 학생이 가입과 동시에 반에 등록
         → 학생이 /질문하기 에서 선생님 고르고 질문
            → 강사 자료 근거로 스트리밍 답변 + 출처 표시
```

---

## 역할별 기능

### 👑 원장 (학원장)
- 가입 = 학원 개설, **아이디**로 로그인 (이메일 불필요)
- 대시보드: 강사·학생 수, 기간별(7/30/90일) 질문 수, **일별 질문 추이 그래프**
- 소속 강사 목록: 과목·자료 수·학생 수·**도움됨/아쉬움 평가 집계**, 강사별 학생 펼쳐 보기
- 강사 **공개/숨기기** 토글, 강사 초대 QR·링크 발급
- 무료/Pro 플랜 배지

### 🧑‍🏫 강사
- 프로필: 이름·과목·**말투 설정**(답변 톤에 그대로 반영)·공개 여부
- 자료 등록: 텍스트 붙여넣기 / **PDF 업로드**(스캔 PDF는 AI 비전으로 글자 인식), 수정·삭제
- 강좌(반) 분류: 자료를 반별로 나눠 담기, 공용 자료는 모든 반 검색에 포함
- 학생 초대: QR·링크 → 가입 즉시 기본반 등록
- **자가 테스트**: 내가 올린 자료로 AI가 어떻게 답하는지 즉석 확인
- **인사이트**: 14일 질문 추이, 평가 집계, 낮은 평점 답변, **"자료 공백"**(근거 자료가
  없거나 관련도 낮게 답한 질문 → 여기를 보강하면 됨)
- **질문 이력 + 미해결 큐**: 학생이 "아쉬워요" 준 대화만 모아 보기
- **학생별 리포트**: 14일간 학생마다 질문 수·아쉬움 수·최근 질문
- **문제 출제**: 자료마다 "문제 만들기" → AI가 4지선다 자동 생성 (자료에 있는 내용만)

### 🧑‍🎓 학생
- 가입/로그인 후 이용 (아이디 로그인 지원, 이메일 없어도 됨)
- 초대 링크로 가입하면 학원 강사 전원 반에 자동 연결 → 바로 질문 가능
- **질문·답변**: 선생님 선택 → 스트리밍 답변, **출처 보기**, 답변 평가(도움됐어요/아쉬워요),
  중단·재전송, 유사 질문 추천, 인기 질문에서 바로 질문
- **내 대화내역**: 지난 질문 다시 보기·이어가기
- **문제풀이**: 즉시 채점·해설
- **오답노트**: 틀린 문제만 모임 → 다시 맞히면 자동으로 빠짐, "오답만 다시 풀기"
- **기출 문제은행**: 전산회계·세무 기출 **2,035문항**(전 학원 공용) — 과목·유형·영역 필터,
  이론 채점 / 실무 분개 정답 보기 + 자가채점, 기출 오답노트

## 핵심 차별점

| 강점 | 내용 |
|---|---|
| **근거 있는 답** | 인터넷이 아니라 강사가 올린 자료에서만 검색해 답한다 |
| **출처 표시** | 답변마다 어떤 자료를 근거로 했는지 열어 확인 가능 |
| **강사 말투 반영** | 강사가 설정한 톤·설명 구조를 답변이 따른다 |
| **학원 간 완전 격리** | 우리 학원 자료·질문·학생 정보는 다른 학원에서 절대 안 보인다 |
| **기출 2,035문항** | 전산회계 2급·1급, 전산세무 2급 기출 문제은행 기본 제공 |
| **강사용 데이터** | 무슨 질문이 많은지, 어디서 막히는지, 어떤 자료가 비었는지 |
| **PWA 설치** | 앱스토어 없이 홈 화면에 추가해 앱처럼 사용 |

## 요금제 (요약)

| | 무료 | Pro |
|---|---|---|
| 강사당 자료 | 10건 | 무제한 |
| 학원당 일 질문 | 50건 | 무제한 |
| 스캔 PDF 비전 인식 | — | ✅ |
| 기출 문제은행 | ✅ | ✅ |

> 한도는 UI에서 미리 사용량으로 보여주고, 초과 시에도 데이터 손실 없이 안내만 한다.
> 플랜 전환은 현재 운영자 처리.

## 기술 개요 (참고)

- **프론트/백엔드**: Next.js 16 (App Router), Vercel 배포
- **데이터/인증**: Supabase (Postgres + pgvector 벡터검색 + Auth)
- **AI 모델**: 답변 = Claude(기본) → Gemini(폴백), 검색 임베딩 = OpenAI → Gemini
  (키가 없어도 키워드 검색으로 동작 — 자세한 키 발급은 `API-토큰-발급-가이드.md`)
- **보안**: 서버가 모든 접근 제어를 담당, 역할 가드 + 학원(테넌트) 경계 + 소유권 필터 3중

## 현재 완성도

핵심 사용자 여정(가입→질문→답변→문제풀이→오답노트)과 강사·원장 도구가 **실사용 검증**을
마친 상태다. 자동 검증 스위트로 상시 점검한다.

| 검증 | 범위 | 결과 |
|---|---|---|
| E2E | 인증·역할가드·질문답변·퀴즈·문제은행·PWA 전 구간 | 94 통과 |
| 역할 매트릭스 | 역할 × 라우트 교차 접근 전수 | 174 통과 |
| 테넌트 경계 | 학원 2개로 격리 실검증 | 18 통과 |
| RLS | anon 키 직접 접근 차단 | 8 통과 |
