# 학원 AI 튜터 — 서비스 소개

> 강사가 올린 자료를 근거로 학생이 24시간 질문하고, 기출 4,806문항으로 시험까지 준비하는 학원 전용 AI 조교.

기준일 2026-10-15 · 서비스 버전 v0.60.0

---

## 한 줄 요약

**"우리 학원 강사가 가르치는 방식 그대로" 답하는 AI 조교에, 수업 관리와 기출 문제은행을 더했다.**
AI는 강사가 직접 올린 자료를 먼저 찾아 근거로 답하고, 답변마다 어느 자료를 근거로 했는지 **출처**를 보여준다.
학생은 같은 앱에서 수업 달력·과제·자료실을 보고, 전산회계·전산세무·컴활 기출을 실제 시험처럼 푼다.

---

## 어떤 문제를 푸나

- 학생은 수업 끝나고 밤에 막히는데, 그때 물어볼 곳이 없다.
- 일반 AI(챗봇)는 그럴듯하게 답하지만 **우리 학원 교재·풀이법과 다르게** 답해 오히려 혼란을 준다.
- 강사는 같은 질문에 반복해서 답하느라 시간을 뺏긴다.
- 수업 자료·과제·공지가 단톡방과 종이로 흩어져, 누가 뭘 냈는지 확인하기 어렵다.
- 세법은 해마다 바뀌는데, 기출 해설은 **출제 당시 법** 기준이라 학생이 헷갈린다.

→ **강사 자료를 근거로 한 AI**가 1차로 답하고, 수업·과제·기출 풀이 기록이 한곳에 모인다.
강사는 어떤 질문이 많은지·어디서 막히는지·누가 과제를 안 냈는지 데이터로 본다.

---

## 이용 흐름

```
원장이 학원 개설 → 강사 초대 (QR·링크)
   → 강사가 강좌(반)별 ROOM을 만들고 자료 등록 (텍스트 붙여넣기 / PDF, 수업 날짜 지정 가능)
      → ROOM 초대 코드로 학생 가입 → 그 강좌에 바로 등록
         → 학생: 선생님 골라 질문 · 수업 달력·과제 제출 · 기출 CBT
            → 강사·원장: 질문 이력·인사이트·학생 리포트·과제 현황으로 확인
```

## 역할별 기능

### 👑 원장 (학원장)
- 가입 = 학원 개설, **아이디**로 로그인 (이메일 불필요)
- 기간별(7·30·90일) 요약: 등록 자료 수, 학생 질문 수, **실제로 쓰는 학생 N/M명**, 답변 평가
- 일별 질문 추이 그래프, 누적 답변을 **"조교 N시간 분량"**으로 환산, 오늘 질문 사용량
- 학생 참여 목록 — 안 쓰는 학생은 "미사용"으로 표시
- **확인이 필요한 답변** — 학생이 "아쉬워요"를 준 질문·답변 원문을 직접 열람
- 소속 강사 목록, 강사 **공개/숨기기**, 강사 초대 QR·링크
- **수강평 실명 열람**(강사에게는 익명), 학생 연락처·강사 메모 열람

### 🧑‍🏫 강사

**수업 관리 — 강좌 ROOM**
- 강좌(반)마다 ROOM: 자료·수강생 명단·인원수·초대 코드를 ROOM 단위로 관리
- **수업 달력**: 날짜를 골라 올린 자료가 그날 수업으로 묶이고, AI가 학생용 2~3문장 **수업 요약**을 만들어 학생 달력에 띄운다
- **과제 제출 현황**: 수업별 제출 N/전체, 펼치면 제출 내용과 **미제출자 명단**
- **자료 게시판**: 학생이 그대로 내려받는 파일(20MB)·공지 — ROOM 전용 또는 공용

**AI 튜터**
- 프로필: 이름·과목·**말투 설정**(답변 톤에 그대로 반영)·공개 여부
- 자료 등록: 텍스트 / **PDF 업로드**(스캔 PDF는 AI가 글자 인식)
- **자가 테스트**: 내가 올린 자료로 AI가 어떻게 답하는지 즉석 확인
- **학생 화면 미리보기**: 학생에게 보이는 화면을 그대로 확인 (기록은 남지 않음)

**문제·평가**
- **문제 출제**: 자료마다 "문제 만들기" → AI가 그 자료 내용만으로 4지선다 자동 생성, 출제 문항 확인·삭제
- **평가 세트**: 엑셀/CSV로 문제 업로드 → 학생 응시(1인 1회, **전자서명** 후 제출) → 자동 채점 → 결과 CSV 내려받기 / 구글시트 자동 전송

**학생 데이터**
- **인사이트**: 14일 질문 추이, 평가 집계, 낮은 평점 답변, **"자료 공백"**(근거 자료 없이 답한 질문 → 여기를 보강하면 됨)
- **질문 이력 + 미해결 큐**: 누가 무엇을 물었는지, "아쉬워요" 받은 대화만 모아 보기
- **학생별 리포트**: 질문 수·아쉬움 수·최근 질문 + **접속 횟수·출석일·마지막 접속**
- 학생 연락처·메모, 임시 비밀번호 발급(아이디를 잊은·잠긴 학생 구제)
- 수강평(익명) 평균·코멘트, 학생 기출 풀이 통계 조회

### 🧑‍🎓 학생
- 가입: 이름·아이디·휴대폰 번호 (첫 비밀번호 = 휴대폰 뒷 4자리). 선생님·ROOM 초대 코드로 바로 연결
- **질문·답변**: 선생님·강좌 선택 → 스트리밍 답변, **출처 보기**, 답변 평가(도움됐어요/아쉬워요),
  중단·재전송, 유사 질문 추천, 인기 질문에서 바로 질문
- 세법 질문엔 **현행 소득세법 조문**을 근거로 "출제 당시 기준 / 현행 기준"을 나눠 설명
- **수업 달력**(AI 요약)·**과제 제출**·**자료실** 다운로드
- 선생님 출제 문제풀이·평가 응시, **오답노트**(다시 맞혀도 기록은 남고 "극복" 표시)
- **기출 문제은행** (아래)
- **마이페이지**: 학습 요약, **연속 출석일**, 시험 기록, 풀이 통계, 내 선생님, 수강평 작성

## 기출 문제은행 (전 학원 공용)

| 과목 | 문항 | 구성 |
|---|---|---|
| 전산회계 2급 | 1,047 | 이론 581 · 실무 466 |
| 전산회계 1급 | 887 | 이론 555 · 실무 332 |
| 전산세무 2급 | 1,166 | 이론 585 · 실무 581 |
| 전산세무 1급 | 906 | 이론 588 · 실무 318 (법인세 포함) |
| 컴퓨터활용능력 2급 필기 | 800 | 2013~2020년 20회차 |
| **합계** | **4,806** | |

- 전산회계·세무는 86회부터 최근 회차까지 과목별 37~40개 회차
- **풀이 모드 3가지**
  - **CBT** — 실제 시험처럼. 회차를 고르면 시험지 문항 순서 그대로, 끝까지 풀고 일괄 채점 → 전 문항 펼쳐 정답·오답 확인
  - **한 문제씩** — 즉시 채점·해설. 모르면 "몰라요" 버튼으로 정답 보고 오답노트에 담기
  - **공부 모드** — 정답·해설을 문제 옆에 펼쳐 두고 넘겨 보기
- **문제검색**: 키워드로 지문·보기 검색(검색어 빨간 강조), 이론/실무 탭, 급수·영역·유형 필터,
  소득세는 9개 파트(근로소득·소득공제 등)로 한 번 더
- 실무는 분개 정답을 **차변/대변 표**로, 증빙 서식(세금계산서·카드매출전표)은 표 그대로 보여준다
- 기출 오답노트, **시험 기록**(회차별로 뭘 틀렸는지 다시 보기), 과목·유형별 **정답률 차트**
- **엑셀 연습장** (컴활 2과목): 문제의 보기 수식을 버튼 하나로 칸에 넣어 결과 확인.
  함수 130개, 절대/상대 참조(F4), 채우기 핸들 등 엑셀처럼 동작. 따로 쓰는 연습장 화면도 제공

## 핵심 차별점

| 강점 | 내용 |
|---|---|
| **근거 있는 답** | 인터넷이 아니라 강사가 올린 자료를 먼저 찾아 근거로 답한다 |
| **출처 표시** | 답변마다 어떤 자료를 근거로 했는지 열어 확인 가능 |
| **강사 말투 반영** | 강사가 설정한 톤·설명 구조를 답변이 따른다 |
| **현행 세법 반영** | 소득세법 현행 조문을 공용 참고자료로 깔아, 기출 해설과 달라진 부분을 구분해 설명 |
| **수업 관리까지 한 앱에** | 강좌 ROOM·수업 달력·과제 제출·자료실 — 단톡방·종이 없이 |
| **기출 4,806문항** | 전산회계 1·2급, 전산세무 1·2급, 컴활 2급 필기. CBT·오답노트·시험 기록 |
| **학원 간 완전 격리** | 우리 학원 자료·질문·학생 정보는 다른 학원에서 절대 안 보인다 |
| **강사·원장용 데이터** | 무슨 질문이 많은지, 어디서 막히는지, 누가 안 쓰는지, 누가 과제를 안 냈는지 |
| **PWA 설치** | 앱스토어 없이 홈 화면에 추가해 앱처럼 사용 (삼성 인터넷·카카오톡 안내 포함) |

## 보안·시험 관리

- **학원 간 완전 격리** + 서버가 모든 접근을 검사(역할·학원·소유권 3중). 브라우저에서 DB를 직접 부르는 경로도 차단
- 학생 화면은 **복사·붙여넣기·드래그·우클릭 차단** + 학생 아이디 **워터마크**(유출본 추적용)
- 평가는 **1인 1회**, 제출 전 **손글씨 전자서명** + 접속 IP 기록
- 로그인 7일 후 자동 로그아웃 (학원 공용 PC 대비)
- 한계: 스크린샷·다른 기기로 촬영하는 것은 웹에서 막을 수 없다 (워터마크로 추적만 가능)

## 기술 개요 (참고)

- **프론트/백엔드**: Next.js 16 (App Router), Vercel 배포
- **데이터/인증**: Supabase (Postgres + pgvector 벡터검색 + Auth + Storage)
- **AI 모델**: 답변 = Claude(기본) → Gemini(대체), 검색 임베딩 = OpenAI → Gemini
  (키가 없어도 키워드 검색으로 동작 — 키 발급은 `API-토큰-발급-가이드.md`)
- **현행 법령**: 국가법령정보센터 오픈API 원문 그대로 (요약·가공 없음)
- **엑셀 연습장**: 수식 엔진 자체 구현 (외부 라이브러리 없음)
- **보안**: 서버가 모든 접근 제어를 담당 — 역할 가드 + 학원(테넌트) 경계 + 소유권 필터

## 현재 완성도

핵심 사용자 여정(가입 → 질문·답변 → 수업·과제 → 기출 CBT → 오답노트·시험 기록)과
강사·원장 도구가 **실사용 검증**을 마친 상태다. 자동 검증 스위트로 배포 전마다 점검한다.

| 검증 | 범위 | 결과 (최근 실행) |
|---|---|---|
| E2E | 인증·역할가드·질문답변·수업·과제·게시판·평가·문제은행·PWA 전 구간 | 284건 중 282 통과 (10-15) |
| 역할 매트릭스 | 역할 × 화면·API 교차 접근 전수 | 212 통과 (10-15) |
| 학원 경계 | 학원 2개를 만들어 격리 실검증 | 19 통과 (08-25) |
| DB 직접 접근 차단 | 브라우저 키로 DB 직접 호출 시 차단 | 8 통과 (08-25) |
| 엑셀 수식 엔진 | 함수·참조·채우기 + 컴활 기출 수식 보기 정답 대조 | 220 통과, 기출 8/8 일치 (10-08) |

> E2E 실패 2건은 휴대폰 가입 테스트 항목으로, 최근 변경과 무관하게 이전부터 나던 것이다.

## 알려진 한계

- 컴활 2급은 **해설이 없다** — 출처 사이트가 해설의 DB 저장을 금지한다. 2013~2016년 문항은 Windows 7·엑셀 2010 기준
- 현행 법령은 **소득세법 본문**이 반영됐고, **시행령은 적재 중**이다 (AI 임베딩 일일 한도 때문에 나눠 넣는 중)
- 실무 문항은 전표·결산까지 — 부가세신고서·원천징수 같은 KcLep 화면 조작형은 제외
- 자료 등록은 텍스트·PDF만 (한글·워드·이미지 파일은 PDF로 바꿔서)

> 기능 전체 목록·상태·한계는 `구현내역서.md`, 변경 이력은 `작업내역.md` 참고.
