# 문제은행 적재 규칙

기출문제를 `bank_questions`로 가져올 때 지켜야 하는 규칙. 어기면 "125회 (22문항)"이라
보여놓고 실제론 문제가 빠져 있는 식의 불일치가 생긴다 (2026-08-19 실제 발생 → 수정).

## 시험 구조 (정답 기준)

| 과목 | 이론 (4지선다) | 실무 |
|---|---|---|
| 전산회계 1·2급 | **1~15번, 15문항** | KcLep 프로그램 작업 (분개·결산 등) |
| 전산세무 2급 | **1~15번, 15문항** | KcLep 프로그램 작업 |

- **회차당 이론은 반드시 15문항**이다. 적재 후 15개 미만이면 파이프라인 유실이다.
- 실무 문항 수는 회차·급수마다 다르다 (고정 아님).

## 데이터 규칙

1. **이론 = `category: "이론"` + `choices`(4지선다) + `answer_idx`**
   - 이론 파트의 분개 유형 문제도 4지선다면 이론이다. 답이 분개 텍스트(`answer_text`)인
     것만 실무(`실무분개`/`결산`)로 분류한다.
2. **`source`는 `"<과목> <회차>회"` 형식** (예: `전산회계2급 125회`). 회차 CBT·회차
   드롭다운이 이 문자열을 그대로 쓴다.
3. **중복 키는 `(source, stem)`** — stem 단독이 아니다.
   - 기출은 같은 문제가 여러 회차에 재출제된다. stem 단독 unique면 재출제 문제가
     첫 회차에만 남아 뒤 회차 CBT가 빈다 (125회 이론 3개가 122·119·112회에 흡수됐던 사고).
   - DB 제약: `bank_questions_source_stem_key` = `unique nulls not distinct (source, stem)`
     (마이그레이션 `20260819040000`). `import-bank.ts`의 dedup·upsert 키도 동일.
4. **회차 문항 수 집계(`bank_source_counts` 뷰)는 이론만 센다** — CBT가 이론만 출제하므로
   실무를 합산하면 "22문항"이라 보여주고 15문제만 나오는 착시가 생긴다
   (마이그레이션 `20260819030000`).
5. 회차를 골라 시작하면 **그 회차 이론 전체**를 원래 순서로 출제한다 (`limit=50`,
   문항 수 선택은 랜덤 출제 전용).

## 적재 절차

```bash
# 1. 소스 산출물 확인 (acct_quiz 파이프라인)
#    C:\dev\acct_quiz\pipeline\out\questions.json
# 2. 적재 (재실행 안전 — (source, stem) upsert)
npx tsx scripts/import-bank.ts          # BANK_SRC=<경로> 로 소스 지정 가능
# 3. 스크립트 끝에 나오는 "이론 15문항 미만 회차" 경고 확인
```

## 그림 자료(이미지) 적재 — 표준

문제에 딸린 그림(현금영수증·사업자등록증 같은 증빙)은 텍스트 적재에서 빠진다.
아래 2단계로 붙인다 (125회로 검증한 절차, 2026-08-19):

1. **추출 (acct_quiz)** — `pipeline/extract_images.py`
   ```bash
   python extract_images.py --pdf "raw/제111회 전산회계2급 A형.pdf" --source "전산회계2급 111회"
   # → out/images/<source>/q_p<페이지>_<n>.png + <source>.json
   ```
   - **임베디드 이미지가 아니라 "문제 영역 렌더 캡처"**를 쓴다. PDF 속 증빙은
     표+텍스트+로고 이미지의 합성이라 이미지만 뽑으면 로고 조각(KICC 로고 등)만 나온다.
     문제 문장 끝 ~ 선택지(①) 시작 구간을 2배 해상도로 잘라야 사람이 보던 그림이 나온다
   - 장식(머리글·꼬리글 로고, 반복 xref, 괘선)은 자동 필터
2. **적재 (acct_rag)** — `scripts/import-bank-images.ts`
   ```bash
   npx tsx scripts/import-bank-images.ts "전산회계2급 111회"   # 인자 없으면 전체
   ```
   - Supabase Storage `bank-images`(public)에 업로드 — 키는 ASCII 슬러그
     (`전산회계2급 111회` → `ca2-111/…`, 한글 키는 Storage가 거부)
   - 캡처의 문제 첫 문장(공백 제거 25자)으로 같은 source의 stem을 찾아
     `bank_questions.images`(jsonb, URL 배열)에 연결. 매칭 실패는 경고로 남는다
   - 재실행 안전 (upsert + URL 중복 제거)
3. 화면은 `StemView`가 `images`를 받아 본문 아래 렌더 (공부·한 문제씩·CBT·오답노트 공통)

**현황 (2026-08-19 전 회차 스캔 결과)**: A형 PDF 47개 중 이론부에 그림 자료가 있는
회차는 **111회·118회(전산회계2급) 단 2개** — 둘 다 현금영수증 증빙, 적재 완료.
125회는 이론 그림 자료 없음 (표·자료는 전부 텍스트로 이미 stem에 있음. 실무 파트의
사업자등록증 이미지는 DB에 없는 프로그램 작업 문제 소속이라 제외).
새 회차 추가 시 extract_images.py를 돌려 캡처가 나오면 2번으로 적재하면 된다.
