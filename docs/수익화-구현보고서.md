# 수익화 구현 보고서

2026-07-30. 목표: **월 10만원 매출 가능한 완성도**. 페르소나 에이전트(기획·디자인·개발·PM·QA) 협업으로 진행 — 회의록: `docs/수익화-플랜.md`.

## 진행 순서 (3단계)

1. **수익화 리서치** — 국내(콴다·클래스팅·클라썸·채널톡·김과외·숨고·학원 SaaS) + 글로벌(Khanmigo·Flint·CustomGPT·Chatbase) 가격·수익모델 웹 조사
2. **수익화 기능 구현** — free/pro 플랜, 서버 게이팅, /pricing, 도입 문의
3. **레퍼런스 기반 기능·디자인 개선** — 튜터·과외·상담·교육 서비스 패턴 조사 후 4종 구현

## 수익 모델 (리서치 결론)

- **학원(원장) 대상 B2B 구독 단일 플랜** — 학생 과금은 콴다급 규모라야 성립, 사업자 과금이 업계 표준
- **Pro 99,000원/월** (학원 단위, 강사·자료·질문 무제한 + OCR + 지원). CustomGPT $99 ↔ Chatbase $40 사이 포지션
- 포지셔닝: "관리 도구"가 아니라 **"강사 질문 응대 시간 절약"** (채널톡 논리)
- 결제: PG 미연동 — 도입 문의 → 계좌이체 → 운영자 수동 전환. 월 10만원 = 학원 1곳이면 달성
- 소형 학원 협상 카드: 49,000원 (코드 아님, 오프라인 운영)

## QA 결과

- 자료 게이트 실증: 시드 강사(자료 43건) 등록 시도 → **403 차단 확인** (서버 강제, 우회 불가)
- 문의 API: 필수값 검증·rate limit(4번째 429) 정상
- 비인증 401, 빌드·lint 클린, 홈·/ask·/pricing·퀵칩 스크린샷 검증

## 운영 방법 (월 10만원 버는 법)

1. **배포 선행조건**: Supabase SQL editor에서 `schema.sql`의 플랜 섹션 실행 (`academies.plan`, `plan_inquiries`) — 안 하면 문의 접수 500, 게이팅은 전원 free
2. 문의 확인: Supabase 대시보드 → `plan_inquiries` (status='new')
3. 입금 확인 후 전환: `update academies set plan = 'pro' where slug = '<학원slug>';`
4. 해지: 같은 SQL로 `'free'`

## 백로그 (이번에 안 함 — 근거)

- PG 자동결제: 고객 1~2곳엔 수동이 빠름. 첫 유료 고객 후 재검토
- 학원 인사이트 그래프·학생별 주간 리포트: 데이터 적으면 빈 화면 역효과 (QA 반대의견 수용)
- 유사 질문 추천, 플랜 만료 자동화(`plan_expires_at`): 고객 10곳 넘으면
- 비밀번호 재설정: 수익화와 무관하나 실사용 전 필수 — 다음 스프린트 1순위 권고
