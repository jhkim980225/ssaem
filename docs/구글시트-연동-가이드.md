# 구글시트 연동 가이드

학생이 평가를 제출하면 **결과가 구글시트에 자동으로 한 줄씩 쌓인다.**
이 문서대로 한 번만 설정하면 된다. (설정 안 해도 앱은 정상 동작한다 — 시트 전송만 건너뛴다)

> 시트 연동 없이 결과만 받고 싶으면: 강사 대시보드 → 평가 → **결과 CSV** 버튼.
> 받은 파일을 시트에 붙여넣으면 같은 내용이다.

---

## 1. 구글 클라우드에서 서비스 계정 만들기

"서비스 계정"은 사람 계정이 아니라 **프로그램이 쓰는 계정**이다. 우리 서버가 이 계정으로 시트에 쓴다.

1. https://console.cloud.google.com 접속 → 프로젝트 만들기 (이름은 아무거나, 예: `ssaem-sheets`)
2. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → `Google Sheets API` 검색 → **사용 설정**
3. **API 및 서비스 → 사용자 인증 정보** → 상단 **사용자 인증 정보 만들기 → 서비스 계정**
   - 이름: 아무거나 (예: `ssaem-writer`) → 만들고 계속 → 완료
4. 만들어진 서비스 계정 클릭 → **키** 탭 → **키 추가 → 새 키 만들기 → JSON** → 다운로드

받은 JSON은 이렇게 생겼다:
```json
{
  "type": "service_account",
  "client_email": "ssaem-writer@ssaem-sheets.iam.gserviceaccount.com",
  "private_key": "-----BEGIN PRIVATE KEY-----\nMIIEv...\n-----END PRIVATE KEY-----\n",
  ...
}
```
여기서 **`client_email`** 과 **`private_key`** 두 개만 쓴다.

---

## 2. 시트 만들고 서비스 계정에 공유하기

1. 구글시트 새로 만들기 (예: "평가 결과")
2. 우측 상단 **공유** → 위 `client_email` 주소를 넣고 **편집자**로 추가 → 전송
   - ⚠️ 이 단계를 빠뜨리면 권한 오류가 난다. 서비스 계정도 "사람처럼" 공유를 받아야 접근할 수 있다.
3. 주소창에서 시트 ID를 복사한다:
   ```
   https://docs.google.com/spreadsheets/d/【이 부분이 시트 ID】/edit
   ```

---

## 3. `.env.local`에 넣기

```
GOOGLE_SA_EMAIL=ssaem-writer@ssaem-sheets.iam.gserviceaccount.com
GOOGLE_SA_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nMIIEv...\n-----END PRIVATE KEY-----\n"
GOOGLE_SHEET_ID=1AbCdEfG...
GOOGLE_SHEET_TAB=결과
```

- **`GOOGLE_SA_PRIVATE_KEY`**: JSON의 `private_key` 값을 **따옴표째 그대로** 붙여넣으면 된다.
  줄바꿈이 `\n` 문자로 들어있는 상태 그대로여야 한다 (서버가 알아서 되돌린다).
- **`GOOGLE_SHEET_TAB`**: 시트 아래쪽 탭 이름. 생략하면 `결과`.
- `.env.local`은 `.gitignore`에 있어 깃허브에 올라가지 않는다.

배포(Vercel)에서는 **Settings → Environment Variables** 에 같은 이름으로 넣고 재배포한다.

---

## 4. 확인

```bash
npx tsx scripts/test-sheets.ts        # 형식 검사 (키 없어도 실행됨)
npx tsx scripts/resync-sheets.ts --dry # 보낼 대상만 확인 (실제 전송 없음)
npx tsx scripts/resync-sheets.ts       # 미전송분 실제 전송
```

설정이 끝나면 학생이 평가를 제출할 때마다 시트에 자동으로 한 줄 추가된다.
시트가 비어 있으면 **헤더 행을 자동으로 먼저** 넣는다.

## 들어가는 내용

| 컬럼 | 설명 |
|---|---|
| 제출시각 | 한국 시간 `YYYY-MM-DD HH:MM` |
| 학원 | 학원 이름 |
| 강사 | 평가를 올린 선생님 |
| 평가명 | 평가 이름 |
| 학생 | 응시한 학생 이름 |
| 점수 / 총점 / 정답률(%) | 숫자로 들어가 시트에서 바로 계산·차트가 된다 |
| 서명 | 전자서명한 시각. 서명 없이 제출했으면 `없음` |
| 문항별정오 | 1번부터 순서대로 `O`(정답) `X`(오답) `-`(미응답) |

컬럼을 바꾸려면 `src/lib/results-csv.ts`의 `CSV_HEADER`와 `src/lib/sheets.ts`의 `toSheetRow`만 고치면 된다(CSV 다운로드와 같은 정의를 공유한다).

---

## 실패해도 결과는 안 사라진다

시트 전송은 **부가 기능**이라 실패해도 응시 결과를 막지 않는다.

- 정답은 항상 **DB에 먼저 저장**되고, 그다음 시트로 보낸다
- 시트가 느리면 5초에서 끊고 제출을 마무리한다 (학생을 기다리게 하지 않는다)
- 못 보낸 건은 `assessment_attempts.synced = false`로 남는다
- 나중에 `npx tsx scripts/resync-sheets.ts` 한 번 돌리면 밀린 것이 전부 들어간다

그래서 **나중에 연동을 켜도** 그동안 쌓인 응시 결과를 한 번에 넣을 수 있다.

## 문제가 생기면

| 증상 | 원인·해결 |
|---|---|
| `sheets 403` | 시트를 서비스 계정 이메일에 **편집자**로 공유했는지 확인 |
| `sheets 404` | `GOOGLE_SHEET_ID`가 틀림 (URL의 `/d/` 뒤 부분) |
| `DECODER routines::unsupported` | `GOOGLE_SA_PRIVATE_KEY`가 깨짐 — JSON의 `private_key`를 따옴표째 그대로 넣었는지 확인 |
| `google token 400` | 서비스 계정 이메일과 키가 서로 다른 계정의 것 |
| 아무 일도 안 일어남 | env 3개(`SA_EMAIL`·`SA_PRIVATE_KEY`·`SHEET_ID`)가 다 있어야 동작한다. 하나라도 없으면 조용히 건너뛴다 |
