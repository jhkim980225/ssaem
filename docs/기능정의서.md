# 기능정의서 — 학원 AI 튜터

**버전** 1.2 · **기준일** 2026-08-10 · **작성 근거** 코드 실측(라우트·페이지 전수) + E2E 64케이스

| 항목 | 내용 |
|---|---|
| 서비스 | 학원 전용 AI 조교. 강사가 자기 자료를 등록하면 학생이 그 강사를 골라 질문하고, **그 강사 자료를 근거로** 답변을 받는다 |
| 범위 | 웹앱(PWA) 전 기능. 결제 시스템(PG)·모바일 네이티브 앱은 범위 밖 |
| 관련 문서 | 구현 상세 `기능-명세.md` / 역할별 현황 `권한별-구현현황.md` / 인증 `인증-로직.md` / DB `db-design.md` |

## 1. 용어

| 용어 | 정의 |
|---|---|
| 학원 | 과금·격리 단위(테넌트). 원장 1명이 개설 |
| 강사 | 자료를 등록하고 자기 이름의 튜터를 갖는 사용자 |
| 자료(document) | 강사가 올린 원본 텍스트/PDF. 보존됨 |
| 청크(chunk) | 자료를 검색 단위로 쪼갠 조각 + 임베딩 |
| 근거 | 답변 생성에 사용된 청크. 학생에게 출처로 노출 |
| 강좌(course) | 자료 분류 단위. 미분류 자료는 공용으로 모든 강좌 검색에 포함 |

## 2. 사용자 역할

| 역할 | 진입점 | 인증 | 권한 요약 |
|---|---|---|---|
| 학원장 | `/admin` | 가입 시 학원 개설(개설 코드 필요) | 학원 통계, 강사 초대·공개 토글 |
| 강사 | `/teacher` | 전역 코드 또는 원장 초대 링크 | 자료·강좌·학생 초대·인사이트·출제 |
| 학생 | `/ask` | **필수** | 질문·이력·문제풀이·오답노트 |

계층: 학원(원장) → 강사 → 학생. 원장이 강사를, 강사가 학생을 초대한다.

## 3. 기능 목록

### 3.1 인증·계정 (AU)

| AU-02 | 강사 가입 | 강사 | 전역 초대 코드 / 원장 초대 링크 / 학원 slug 링크 | ✅ |
| AU-03 | 학생 가입 | 학생 | 이메일 또는 아이디. 초대 링크는 가입+수강등록 원스텝 | ✅ |
| AU-04 | 로그인 | 전체 | 역할은 서버 `profiles.role` 기준으로 판정, 착지 페이지 자동 결정 | ✅ |

**ASK-03 상세**

- 선행조건: 로그인 + 대상 강사에 자료 1건 이상 등록
- 입력: 질문 텍스트, 강사 ID, (선택) 강좌 ID·대화 ID
- 처리: ① 로그인 검사(미인증 401) ② 분당 20건 rate limit ③ 무료 플랜 일일 한도 확인 ④ 강사 조회·청크 검색·대화 이력 병렬 조회 ⑤ 시스템 프롬프트 조립 ⑥ 스트리밍 ⑦ 스트림 종료 후 이력 기록
- 출력: 답변 텍스트(스트림), 근거 목록, 대화 ID
- 예외: 근거 없음 → 모른다고 답함 / LLM 키 없음 → 검색 결과 미리보기만 / 이력 저장 실패 → 답변에는 영향 없음

## 4. 비기능 요건

| 구분 | 요건 | 현재 |
|---|---|---|
| 응답성 | 첫 토큰까지 체감 지연 최소화 | 스트리밍. 강사 조회·검색·이력을 병렬 처리 |
| 가용성 | 외부 API 장애에도 서비스 지속 | 3계층 폴백: 답변(Anthropic→Gemini→검색결과만), 임베딩(OpenAI→Gemini→없음), 검색(pgvector→어휘 랭킹) |
| 정확성 | 강사 자료에 없는 내용을 지어내지 않음 | 근거 없으면 모른다고 답하도록 프롬프트 강제. 출제도 동일 원칙 |
| 보안 | 역할·소유권 이중 검사 | 서버 전 라우트 `requireRole()` + 쿼리 소유권 필터. 2026-08-09 감사 기준 누락 없음 |
| 확장 제약 | 임베딩 차원 `vector(1536)` 고정 | 변경 시 스키마·기존 데이터 전면 재작업 |
| 알려진 위험 | rate limit이 인메모리 | 서버리스 다중 인스턴스에서 인스턴스별 카운트 |

## 6. 인수 기준

```bash
npx tsx scripts/e2e.ts                            # 로컬 (서버 실행 필요)
E2E_BASE=https://<도메인> npx tsx scripts/e2e.ts   # 배포본
```

인증·역할가드·질문답변·대화내역·퀴즈·PWA를 실제 HTTP로 검증. 테스트 데이터는 `[E2E]` 태그로 자동 정리.
