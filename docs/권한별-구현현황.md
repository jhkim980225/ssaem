# 권한별 구현 현황

역할(권한)별로 구현된 것 / 안 된 것 정리. 라우트별 인증 가드는 코드 실측 기준 (2026-07-30, 에이전트 감사).

## 요약

| 역할 | 구현도 | 핵심 |
|---|---|---|
| 학원장 (admin) | `████████░░` | 학원 개설·통계·강사 초대·강사별 학생 목록. 관리(제거/수정) 기능 없음 |
| 강사 (teacher) | `█████████░` | 자료·강좌·초대·인사이트·이력 전부. 학생 관리 화면만 없음 |
| 학생 (student) | `█████████░` | 질문·이력·피드백·초대 등록 전부. 계정 관리(비번 변경 등) 없음 |
| 익명 | `██████████` | 공개 강사 질문 (의도된 전부) |

## 학원장 (admin) — `/admin`

**됨**
- 가입 = 학원 개설 (slug 자동), 로그인 (로그인 우선 UI)
- 대시보드: 강사 수·학생 수·7일 질문 수 통계
- 소속 강사 목록 (과목·자료 수·공개 여부) + 강사별 학생 목록 펼침
- 강사 초대 QR/링크 (HMAC kind=t) — 초대 가입은 전역 INVITE_CODE 불필요, 자동 소속
- 권한 가드: `/api/admin`은 role=admin 검사(403), admin 계정의 강사 프로필 API role 강등 차단

**안 됨**
- 강사 제거/정지, 학원 정보 수정(이름·slug)
- 학원 단위 인사이트 (질문 추이 그래프·강사별 품질 비교)
- 원장의 강사 자료/이력 열람, 학생 제명
- 원장 계정 다중/양도, 결제·플랜 (SaaS 과금)

## 강사 (teacher) — `/teacher`

**됨**
- 가입 (전역 INVITE_CODE 직접 가입 / 원장 초대 `/join-teacher/<code>` / 학원 slug 링크)
- 프로필: 이름·과목·말투(tone_note→프롬프트 반영)·공개 여부 토글
- 자료: 텍스트/PDF 등록(스캔 PDF는 비전 OCR 폴백), 수정(재청킹), 삭제(confirm), 감사 이력
- 강좌: 생성/삭제, 자료 강좌 분류 (공용 자료는 모든 강좌 검색 포함)
- 학생 초대 QR/링크 (kind=s) — 학생 가입과 동시에 기본반 수강 연결
- 자가 테스트 채팅, 질문 이력(학생 평가 배지), 인사이트(질문 추이·낮은 평점·자료 공백)

**안 됨**
- 내 학생 명단 관리 화면 (현재 원장 대시보드에만 있음)
- 학생별 학습 현황·개인 리포트
- 초대 코드 회전/만료 (발급자당 고정)
- 강좌별 학생 배정 (수강 연결은 기본반 고정), 자료의 강좌 이동
- 새 질문 알림 (이메일/푸시)

## 학생 (student) — `/ask`

**됨**
- 가입/로그인 (선택 — 익명 질문도 가능), 초대 링크 `/join/<code>`로 가입+등록 원스텝
- 강사 선택 (초대된 비공개 강사 포함, "내 선생님" 배지·상단 정렬, `?teacher=` 자동 선택)
- 강좌 칩 필터 질문, 스트리밍 답변 (중단 ■, 실패 시 질문 복원 재전송, 멀티라인 입력)
- 출처 보기 (근거 청크 미리보기), 답변 피드백 👍/👎
- 내 질문 이력 목록·이전 대화 이어가기

**안 됨**
- 프로필 수정 (이름·비밀번호 변경 UI), 비밀번호 재설정 (잊어버리면 복구 불가)
- 등록(수강) 해지, 대화 삭제
- 강좌 수강신청 UI — 현재 강좌는 자유 선택 (enrollments는 기본반만)

## 익명

**됨**: 공개 강사에게 질문 (이력 미저장), 학원별 진입 `/a/<slug>`, rate limit 적용(질문 20/분)
**안 됨 (의도)**: 비공개 강사 접근, 이력 저장

## 알려진 권한 갭 (경미 — 실측에서 발견)

- `/api/courses` POST/DELETE, `/api/invite` GET, `/api/insights` GET: 인증만 있고 role 검사 없음 — **학생 계정도 호출 가능**. 실해는 낮음(학생이 발급한 초대 코드는 join 시 강사 검증에서 거부, 강좌는 자기 소유로만 생성)이지만 role 가드 추가가 정석
- `teacherFromRequest`는 이름과 달리 role 검사 없음 (userFromRequest 별칭) — 소유권은 쿼리 필터로만 강제
- 학생 초대 rate limit 없음(`/api/join` POST) — 인증 필요라 낮은 위험

## 시스템 공통 (역할 무관)

rate limit(질문/가입/코드 검증), 입력 상한, PDF 매직 바이트, HMAC 초대 코드(kind 분리), 멀티테넌트 격리(학원별 목록), E2E 45 asserts 라이브 검증
