## 학원장 (admin) — `/admin`

**됨**
- 가입 = 학원 개설 (개설 코드 필요), 로그인
- 통계: 강사·학생 수, 7일 질문 수, **14일 일별 질문 그래프**
- 소속 강사 목록: 과목·자료 수·학생 수·**도움됨/아쉬움 집계**, 강사별 학생 펼침
- **강사 공개/숨기기 토글** (`PATCH /api/admin`)
- 강사 초대 QR/링크 (HMAC kind=t) — 초대 가입은 전역 코드 불필요, 자동 소속
- 권한: `/api/admin`은 role=admin 강제. 강사·학생 토큰은 403

**안 됨**
- 강사 완전 제거(현재는 숨기기만), 학원 이름·slug 수정
- 원장의 강사 자료·이력 열람, 학생 제명
- 원장 계정 다중/양도, 결제·플랜 자동화 (전환은 운영자 SQL 수동)

## 강사 (teacher) — `/teacher`

**됨**
- 가입 (전역 `INVITE_CODE` / 원장 초대 `/join-teacher/<code>` / 학원 slug 링크)
- 프로필: 이름·과목·말투(tone_note→프롬프트 반영)·공개 여부
- 자료: 텍스트/PDF 등록(스캔 PDF는 비전 OCR, Pro 전용), 수정(재청킹), 삭제, 감사 이력
- 강좌: 생성/삭제, 자료 분류 (공용 자료는 모든 강좌 검색 포함)
- 학생 초대 QR/링크 (kind=s) — 가입과 동시에 기본반 연결
- 자가 테스트 채팅 (본인 토큰으로 기록 — 학생 통계 오염 없음)
- 인사이트: 14일 질문 추이·평가 집계·낮은 평점 답변·**자료 공백**(근거 없음/유사도 0.45 미만)
- 질문 이력 + **미해결 큐**(👎 받은 대화 필터)
- **학생별 리포트** — 14일 학생별 질문·아쉬움·최근 질문
- **문제 출제** — 자료마다 "문제 만들기"로 LLM이 4지선다 생성. 출제한 문항은 그 자료 카드에서 펼쳐 확인·개별 삭제

**안 됨**
- `kind='style'`(말투 자료) 등록 UI — 스키마·시드에만 존재
- 초대 코드 회전/만료 (발급자당 고정)
- 강좌별 학생 배정(기본반 고정), 자료의 강좌 이동
- 새 질문 알림 (이메일/푸시)

## 학생 (student) — `/ask`, `/quiz`

**됨**
- 가입/로그인 **필수** (질문·문제풀이 전부), 아이디 로그인 지원
- 초대 링크 `/join/<code>` 가입+등록 원스텝. 일반 가입도 학원 강사 전원에 자동 수강 연결
- 강사 선택(초대된 비공개 강사 포함), 강좌 칩 필터, 예시 질문 퀵칩
- 스트리밍 답변 (중단·재전송·멀티라인), 출처 보기, 답변 평가
- 유사 질문 추천, 인기 질문 랭킹에서 바로 질문
- 질문 이력 목록·이어가기, **`/my/history` 전용 대화내역**
- **문제풀이** `/quiz` — 즉시 채점·해설
- **오답노트** `/quiz/notes` — 틀린 문제만, 맞히면 자동 제외, 오답만 다시 풀기

**안 됨**
- 프로필 수정 (이름·비밀번호 변경 UI). 비밀번호 재설정은 `/reset`으로 가능하나 **아이디 계정은 메일 수신 불가**
- 등록(수강) 해지, 대화 삭제
- 강좌 수강신청 UI (enrollments는 기본반 고정)

## 익명 (비로그인)

**됨**: 랜딩·요금제·약관·설치 안내, 가입/로그인, 초대 링크 가입
**안 됨 (의도)**: 질문·문제풀이·오답노트 전부 로그인 필수 (2026-08-10 변경). 관련 API는 401

## 권한 가드 현황

2026-08-10 기준 **역할 검사 누락 없음**. `requireRole()`(`src/lib/auth.ts`)로 통일:

| 요구 역할 | 라우트 |
|---|---|
| 강사 | documents, documents/events, upload, insights, invite, students, quiz/generate, courses(쓰기·내 목록) |
| 원장 | admin (GET·PATCH) |
| 강사이거나 프로필 없음 | profile POST |
| 로그인만 (`requireUser`) | ask, feedback, quiz, quiz/attempt, related, popular, teachers, courses(`?teacher=`) |
| 공개 | inquiry, signup, join, join-teacher |

E2E 검증: 학생→강사 API 7종 403, 강사↔원장 상호 403, 각 역할 정상 경로 200.

**과거에 있었고 지금은 없는 문제**
- ~~`/api/profile` POST가 호출자를 무조건 강사로 승격~~ → 차단
- ~~courses·invite·insights에 role 검사 없음~~ → `requireRole` 적용
- ~~로그인 착지가 탭 선택값 기준~~ → 서버 `profiles.role` 기준

## 시스템 공통

rate limit(질문·가입·문의·채점), 입력 상한, PDF 매직 바이트, HMAC 초대 코드(kind 분리), 멀티테넌트 격리, 대화 소유권 검증, 피드백 소유권 검증, 인기 질문 2회 이상만 노출.

**남은 위험**: rate limit이 인메모리라 서버리스 다중 인스턴스에서 인스턴스별로 카운트된다. 상세는 `docs/인증-로직.md`.
