## 질문·답변 (핵심 경로)

`/ask` 3열 구성:

- **좌**: 선생님 검색·목록(자료 수), 내 질문 이력(전체 보기 → `/my/history`)
- **중앙**: 히어로 + "요즘 많이 묻는 질문" 랭킹 / 대화 시작 후엔 채팅
- **우**: 학습 현황, 질문 많은 선생님 비중, 질문 팁

`POST /api/ask` 동작:

1. 로그인 검사(`requireUser` — 미인증 401) → rate limit(IP당 분당 20) → 무료 플랜 일일 한도 확인
2. **대화 소유권 검증** — 남의 `conversationId`면 무시하고 새 대화로 분리
3. 강사 조회 + 청크 검색 + 대화 이력을 `Promise.all` 병렬
4. 시스템 프롬프트 조립(`lib/prompt.ts`) → `ReadableStream`으로 스트리밍
5. 스트림 종료 **후** 비동기로 이력 기록 (실패해도 답변엔 영향 없음)

주의점:
- `conversation`은 스트리밍 시작 **전에** 만들어 `X-Conversation-Id` 헤더로 전달 (스트리밍 중엔 헤더 변경 불가)
- 근거 미리보기도 같은 이유로 `X-Sources` 헤더에 URI 인코딩해 실어 보냄
- 클라이언트가 중간에 끊어도 이력 저장이 죽지 않게 `enqueue`를 try/catch로 감쌈

부가 기능: 예시 질문 퀵칩, 강좌 칩 필터, 출처 보기, 답변 평가(도움됐어요/아쉬워요), "이런 질문도 있어요"(유사 질문 추천), 중단 버튼, 실패 시 질문 복원.

## 자료 등록 (강사)

```
텍스트 입력 또는 PDF 업로드
  → (PDF) unpdf로 텍스트 추출, 없으면 LLM 비전 OCR 폴백
  → chunkText()
  → embedMany() 배치 임베딩
  → documents(원본) + chunks(조각+임베딩) 저장
```

- 원본을 `documents.raw_text`에 보존 → 수정 시 재청킹
- 상한: 텍스트 200,000자, PDF 15MB. PDF는 매직 바이트(`%PDF`)로 실제 형식 확인
- 감사 로그: `document_events`에 등록·삭제 기록 (문서가 지워져도 기록 유지)
- 강좌 분류 가능. `course_id`가 NULL이면 공용 자료 → 모든 강좌 검색에 포함

## 문제풀이 · 오답노트

마이그레이션 `20260806000000_quiz_and_plan.sql` 적용 완료 (2026-08-10). 운영 중.

출제:
- 강사 대시보드의 자료마다 "문제 만들기" → `POST /api/quiz/generate`
- 말투 자료(`kind='style'`)는 출제 불가 — 서버 400 + 버튼 미노출. "AI가 어떻게 답할지" 지시문이라 학생용 문제가 안 됨
- LLM이 그 자료만 근거로 4지선다를 만든다. 프롬프트에 "자료에 없는 내용 생성 금지", "정답을 확정할 수 없으면 만들지 않음"을 명시
- 형식이 깨진 문항은 저장 전에 버림. 강사당 분당 5회 제한

풀이·채점:
- `GET /api/quiz?teacher=&course=&mode=all|wrong` — **응답에 정답·해설을 넣지 않는다** (네트워크 응답만 보고 답을 아는 것 차단)
- `POST /api/quiz/attempt` — 서버에서 채점하고 그때 정답·해설을 준다. 로그인 학생이면 `quiz_attempts`에 기록

오답노트:
- **마지막 시도가 오답**인 문제만 모인다. 다시 풀어 맞히면 자동으로 빠짐
- 각 문항에 정답(파랑)·내가 고른 답(빨강)을 나란히 표시
- "오답만 다시 풀기"(`?mode=wrong`)

## 강사 도구

- **인사이트** — 14일 질문 추이 막대그래프, 도움됨/아쉬움 집계, 낮은 평점 답변, **자료 공백**(근거 없이 답했거나 유사도 0.45 미만인 질문)
- **질문 이력** — 학생 대화 전체. 👎 받은 대화를 "확인 필요"로 묶는 미해결 큐
- **학생별 리포트** — 14일 학생별 질문 수·아쉬움 수·최근 질문 (`role=student`만 집계)
- **학생 초대** — QR + 링크. 가입과 동시에 내 기본반에 등록
- **자가 테스트** — 등록 자료로 내 튜터가 어떻게 답하는지 즉시 확인

## 원장 도구

- 학원 통계(강사·학생·7일 질문 수), 14일 질문 추이 그래프
- 소속 강사 목록 — 자료 수·학생 수·도움됨/아쉬움, 강사별 학생 펼침
- 강사 **공개/숨기기 토글** (`PATCH /api/admin`)
- 강사 초대 QR/링크
- 플랜 배지 (Pro / 무료)

## 요금제

- `academies.plan` = `free` | `pro`. 전환은 운영자가 SQL로 수동 (PG 미연동)
- 무료 한도: 강사당 자료 10건, 학원당 일 질문 50건, 스캔 PDF OCR은 Pro 전용
- 한도 강제는 **서버**에서만 (`lib/plan.ts`). UI는 안내만
- `/pricing` 도입 문의 → `plan_inquiries` 테이블. 조회는 Supabase 대시보드에서

## PWA

스토어 없이 홈 화면 설치. `/install`에 QR + iOS/Android 안내.

- `manifest.ts` — `start_url: /ask`, `display: standalone`
- 아이콘은 `next/og`로 동적 생성(`/pwa-icon/192`, `/512`, `/apple-icon`) — 레포에 바이너리 없음
- iOS는 매니페스트 icons를 무시하므로 `metadata.appleWebApp` + apple-touch-icon 필요
- Android는 `beforeinstallprompt`를 가로채 설치 버튼 제공. iOS는 이 이벤트가 없어 수동 안내

## 프로바이더 폴백 체인

API 키 유무에 따라 단계적으로 동작 수준을 낮춘다. 교체 시 해당 lib 파일 하나만 고치면 되도록 격리돼 있다.

| 기능 | 우선 | 폴백 | 전무할 때 |
|---|---|---|---|
| 답변 생성 (`lib/anthropic.ts`) | `ANTHROPIC_API_KEY` | `GEMINI_API_KEY` (429면 flash-lite로 재시도) | 생성 생략, 검색 결과만 반환 |
| 임베딩 (`lib/embed.ts`) | `OPENAI_API_KEY` | `GEMINI_API_KEY` (3072→1536 MRL 축소) | `null` |
| 검색 (`lib/retrieve.ts`) | pgvector `match_chunks` | lexical 랭킹 (`lib/lexical.ts`) | — |

임베딩 차원은 `vector(1536)` 고정. 바꾸면 스키마와 기존 데이터를 전부 재작업해야 한다.

## 검증

```bash
npx tsx scripts/e2e.ts                                    # 로컬 (서버 실행 필요)
E2E_BASE=https://<도메인> npx tsx scripts/e2e.ts           # 배포본
npx tsx scripts/test-chunk.ts                             # 청킹 (외부 키 불필요)
npx tsx scripts/verify-instructors.ts                     # 자료·검색·프롬프트
```

`scripts/e2e.ts`는 실제 HTTP로 인증·역할가드·질문답변·대화내역·퀴즈·PWA를 검증한다. 생성한 데이터는 `[E2E]` 태그를 붙여 끝에 정리한다. 테이블이 없는 기능은 실패가 아니라 SKIP으로 보고한다.
