# 질문 이력과 자가 테스트 (강사)

## 질문 이력 조회

- `/teacher/history` — 내 앞으로 들어온 학생 대화 목록 (최근 50개, 대화별 메시지 수 표시).
- 대화 선택 시 질문/답변 전체 펼침.
- 본인 대화만 조회 가능.

## 기록되는 것

- 모든 Q&A: 대화(`conversations`) → 메시지(`messages`).
- 답변 메시지에는 사용 모델·응답 지연시간(ms) 저장.
- 답변별 근거 청크와 유사도(`message_citations`) — 어떤 자료가 근거로 쓰였는지 추적 가능.

## 자가 테스트

- 강사 대시보드에 학생과 동일한 채팅 패널 내장.
- 자료 등록 직후 자기 자료 기반 답변 품질을 바로 확인하는 용도.
