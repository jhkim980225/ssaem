# 기능 정의 — 개요

학원 AI 튜터 — 강사가 자기 자료(문제/풀이·설명 스타일)를 등록하면, 학생이 그 강사를 골라 질문하고 **그 강사 자료를 근거로** AI 답변을 받는 RAG 서비스.

## 사용자 역할

| 역할 | 진입점 | 인증 |
|---|---|---|
| 학원장 | `/admin` | 가입 시 학원 개설. 강사 초대 코드/QR 발급 |
| 강사 | `/teacher` 또는 원장 초대 `/join-teacher/<code>` | Supabase Auth (직접 가입은 전역 INVITE_CODE) |
| 학생 | `/ask` (익명 가능) 또는 강사 초대 `/join/<code>` | 로그인 선택 |

계층: 학원(원장) → 강사 → 학생. 원장이 강사를 초대하고, 강사가 학생을 초대한다.
