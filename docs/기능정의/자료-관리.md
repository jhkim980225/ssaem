# 자료 관리 (강사)

강사가 등록한 자료가 학생 답변의 근거가 된다. 자료가 없으면 답변도 근거 없음.

## 자료 종류

| kind | 용도 |
|---|---|
| `problem` | 문제/풀이 자료 — 답변 근거의 본체 |
| `style` | 설명 스타일 자료 — 강사 말투/설명 방식 반영 |

## 강좌 분류

- 강사가 강좌(반)를 만들어 자료를 나눠 담을 수 있음. 강좌 미지정 자료 = 공용(모든 강좌 검색에 포함).
- 강좌 삭제 시 소속 자료는 공용으로 전환 (자료 보존).
- 학생은 질문 화면에서 강좌 칩으로 검색 범위 선택.

## 등록

- **텍스트 직접 입력**: 대시보드에서 붙여넣기.
- **PDF 업로드**: 텍스트 PDF는 즉시 추출. 스캔 PDF는 LLM 비전 OCR 폴백(15MB 이하, OCR용 API 키 필요 — 없으면 안내 후 거부).
- 등록 시 자동 처리: 원본 보존 → 청킹 → 청크별 임베딩 저장.

## 수정

- 텍스트 자료만 원문 교체 방식으로 수정 (자동 재청킹·재임베딩).
- PDF 자료는 수정 불가 — 삭제 후 재업로드.

## 삭제

- 문서 단위 삭제. 소속 청크는 자동 삭제(cascade).
- 본인 자료만 삭제 가능.

## 감사 이력

- 자료 등록/삭제가 이벤트 로그로 기록됨 (제목·종류·출처·청크 수·시각).
- 수정은 삭제+등록 쌍으로 기록.
- 대시보드에서 최근 이력 조회 가능.
