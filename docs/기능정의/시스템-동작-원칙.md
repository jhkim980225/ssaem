# 시스템 동작 원칙

## 근거 기반 답변

- 답변은 검색된 강사 청크를 근거로 생성. 시스템 프롬프트에 근거 주입.
- 강사 이름·과목을 프롬프트에 반영해 그 강사의 튜터로 응답.

## 단계적 성능 저하 (키 없어도 죽지 않음)

| 키 상태 | 동작 |
|---|---|
| LLM 키(Anthropic/Gemini) 있음 | 정상 답변 생성 |
| LLM 키 없음 | 생성 생략, 검색된 근거 미리보기만 반환 (비용 0 체험 모드) |
| 임베딩 키(OpenAI/Gemini) 있음 | 벡터 유사도 검색 |
| 임베딩 키 없음 | 키워드 렉시컬 검색 폴백 |

## 비용 방어

- 대화 맥락 최근 10개 메시지로 제한 (토큰 방어).
- Gemini 무료 일일 쿼터(429) 초과 시 flash-lite 모델 자동 폴백.
- 폴백도 실패하면 학생에게 한국어 안내 메시지 (영문 에러 원문 비노출).
- 문서 등록 시 임베딩 배치 호출 (청크당 1콜 → 1콜).

## 이력 보존

- 모든 Q&A 기록. 클라이언트가 스트리밍 중 이탈해도 이력 저장 보장.
- 이력 저장 실패가 답변 자체를 막지 않음 (역도 동일).
