# 학생 질문

학생은 로그인 없이 `/ask`에서 이용 가능. 로그인(선택)하면 질문 이력이 계정에 저장되고 이어가기 가능.

## 강사 초대 (SaaS 온보딩)

- 강사가 대시보드에서 초대 링크/QR 발급 → 학생이 접속하면 강사 정보 확인 후 가입(또는 로그인)과 동시에 그 강사의 기본반에 수강 연결.
- 등록된 강사는 목록에서 "내 선생님" 배지 + 최상단 정렬, 질문 화면 자동 선택.
- **권한**: 강사가 "공개 목록 노출"을 끄면 초대받은(수강 연결된) 학생에게만 보임.

## 학생 계정 (선택)

- 가입: 이름 + 이메일 + 비밀번호. 초대코드 불필요, 메일 인증 생략.
- 로그인 시 대화가 계정에 연결(`student_id`) — "내 질문 이력"에서 이전 대화 열어 이어가기.
- 비로그인 질문도 계속 동작 (이력만 계정에 안 남음).

## 강사 선택

- 공개(`is_public=true`) 강사 목록에서 선택. 이름·과목·이모지 아바타 표시.
- 학원별 진입 URL `/a/<slug>` → 그 학원 강사만 노출. 슬러그 없으면 전체.

## 질문과 답변

- 질문하면 그 강사 자료에서 관련 청크를 검색해 근거로 답변 생성.
- 답변은 스트리밍 (타자 치듯 실시간 표시).
- 근거 자료가 없으면 지어내지 않고 근거 없음을 명시.
- 마크다운-lite 렌더링: 굵게, 코드, 표, 불릿.

## 대화 이어가기

- 같은 대화 안에서 후속 질문 가능 — 직전 맥락(최근 10개 메시지) 유지.
- 첫 응답 시 대화 ID 발급, 이후 질문에 자동 첨부.

## 오류 시

- 질문 폭주(무료 쿼터 초과) 시 한국어 안내: "잠시 후 다시 시도해 주세요."
- LLM 키 미설정 배포에서는 답변 생성 대신 검색된 근거 미리보기 표시.
