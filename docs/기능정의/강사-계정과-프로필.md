# 강사 계정과 프로필

## 가입

- 이메일 + 비밀번호(6자 이상) + 초대코드로 가입.
- 초대코드는 서버 환경변수 `INVITE_CODE`와 일치해야 함 — 스팸/무단 가입 차단.
- `INVITE_CODE` 미설정 시 가입 열림 (개발 모드, 서버 경고 로그).
- 메일 인증 생략 (`email_confirm: true`로 계정 생성).

## 로그인

- Supabase Auth 이메일/비밀번호 로그인. `/teacher`에서 처리.
- 이후 API 호출은 access_token을 Bearer 헤더로 전달.

## 프로필

- 이름·과목 등록/수정.
- 최초 저장 시 학원 소속 자동 처리 — 기본 학원(`DEFAULT_ACADEMY_SLUG`) 없으면 생성 후 소속.
- 공개 여부(`is_public`) 설정: 비공개면 학생의 강사 목록에서 숨김. 기존 대화는 유지.
