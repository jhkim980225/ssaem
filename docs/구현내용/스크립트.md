# 스크립트 (scripts/)

실행: `npx tsx scripts/<파일>`. 테스트 프레임워크 없음 — assert 기반 셀프체크.

| 파일 | 내용 | 외부 의존 |
|---|---|---|
| `test-chunk.ts` | 전산회계 2급 샘플 문서(`sample-doc.txt`) 청킹 검증 | 없음 |
| `verify-instructors.ts` | 강사 10명 자료/검색/프롬프트 20개 assert (렉시컬 검색 경로 검증) | 없음 |
| `seed.ts` | 강사 10명 + 자료 자동 생성. 로그인 `<id>@a.test / 123456` | Supabase 필요 |
| `instructors.ts` | 시드·검증 공용 강사 10명 데이터 | — |

- 검증 2종은 API 키 불필요 — 임베딩 폴백(lexical)과 프롬프트 조립이 프로덕션 코드와 같은 모듈을 공유하므로 오프라인 검증 가능.
- 환경변수는 `dotenv`로 `.env.local` 로드.
