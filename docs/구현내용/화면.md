# 화면

## 페이지 (src/app)

| 경로 | 파일 | 내용 |
|---|---|---|
| `/` | `page.tsx` | 랜딩 — 강사/학생 진입 분기 |
| `/teacher` | `teacher/page.tsx` | 강사 대시보드: 가입/로그인, 프로필 편집, 자료 등록(텍스트/PDF)·수정·삭제, 자료 이력, 자가 테스트 채팅 |
| `/teacher/history` | `teacher/history/page.tsx` | 질문 이력: `/api/conversations`로 대화 목록(최근 50) 로드, 대화 클릭 시 메시지 lazy 로드·캐시 |
| `/ask` | `ask/page.tsx` | 학생: 강사 목록 → 선택 → ChatPanel. 학생 로그인/가입(선택) + 내 질문 이력·이어가기. `?academy=` 학원 필터 |
| `/a/[slug]` | `a/[slug]/page.tsx` | 학원별 진입 — `/ask?academy=<slug>` redirect |

전부 클라이언트 컴포넌트. 강사 페이지는 `supabase.auth.getSession()`으로 세션 확보 후 access_token을 API 헤더에 첨부.

## 컴포넌트 (src/components)

### ChatPanel.tsx — 공용 채팅

- 강사 자가 테스트와 학생 `/ask`가 같은 컴포넌트 사용.
- `/api/ask` 스트리밍 응답을 읽어 실시간 렌더. 첫 응답의 `X-Conversation-Id` 헤더를 보관해 후속 질문에 첨부.
- 선택 props: `token`(로그인 학생 — Authorization 헤더 첨부), `initialConversationId`/`initialMsgs`(이전 대화 이어가기).
- **마크다운-lite 자체 구현** (라이브러리 없음): `**굵게**`, `` `코드` ``, 표, 불릿만. 모델이 표 정렬용으로 뿜는 연속 공백 제거 방어 포함.

## 기타
