# 인증과 프로필

## 가입 — POST /api/signup

- `role` 파라미터로 분기 (기본 teacher):
  - **강사**: `INVITE_CODE` 환경변수와 초대코드 비교. 불일치 403. 미설정이면 가입 열림(개발 모드, 서버 경고). 프로필은 대시보드에서 이름·과목 저장 시 생성.
  - **학생**: 초대코드 불필요, `name` 필수. 가입 즉시 `profiles`(role=student, 기본 학원) 생성.
- `auth.admin.createUser({ email_confirm: true })` — 메일 인증 생략.
- 중복 이메일은 한국어 메시지로 치환.

## 인증 패턴 — src/lib/auth.ts

- `userFromRequest(req)`: `Authorization: Bearer <access_token>` → Supabase `auth.getUser(token)` 검증 → uid 반환. role 검사 없음 — 소유권은 각 쿼리 eq 필터로 강제. (`teacherFromRequest`는 호환 별칭)
- 세션 쿠키 아님 — 클라이언트가 매 요청 토큰을 헤더로 전달.
- 인증 필요 API 전부 이 함수로 시작. 실패 시 401.

## DB 접근 — src/lib/supabase.ts

- 브라우저: anon 키 클라이언트 (Auth 용도).
- 서버 API: `serviceClient()` — service role, RLS 우회. 소유권은 쿼리 `eq("teacher_id", uid)`로 강제.

## 프로필 — GET/POST /api/profile

- GET: `profiles` + `teacher_profiles(subject, is_public)` 조인 반환.
- POST: 이름·과목·공개 여부 upsert. 학원 미소속이면 기본 학원(`DEFAULT_ACADEMY_SLUG`, 기본 `default`) 조회-없으면-생성 후 소속.

## 강사 목록 — GET /api/teachers

- 공개 강사만: `role=teacher` + `teacher_profiles.is_public=true` inner join.
- `?academy=<slug>` 필터 지원. slug 없으면 전체 공개 강사.
- 학원별 진입: `/a/[slug]` 페이지가 `/ask?academy=<slug>`로 redirect (src/app/a/[slug]/page.tsx).

## 학원별 가입

- `/teacher?academy=<slug>`로 가입하면 signup이 `user_metadata.academy_slug`에 저장 → 프로필 저장 시 `resolveAcademy(slug)`로 그 학원 소속 (없으면 생성 — 초대코드가 게이트).
- 학생 가입도 `academySlug` 전달 시 동일. slug 미전달 시 기본 학원.
- `resolveAcademy`는 동시 가입 unique 충돌을 재조회로 흡수.

## 강좌 — /api/courses (src/app/api/courses/route.ts)

- `GET ?teacher=<id>`: 공개 — 학생 필터 칩용 강좌 목록.
- `GET`(인증): 내 강좌 + 자료 수. `POST {title}`: 생성(프로필의 academy_id 필요). `DELETE ?id=`: 삭제 — 소속 자료는 `course_id` null(공용)로 남음.
- 자료 등록 시 `courseId`는 `ownCourseOrNull()`(src/lib/documents.ts)로 소유 검증 — 내 강좌 아니면 공용 강등.
