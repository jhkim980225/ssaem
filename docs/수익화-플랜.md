# 수익화 플랜 — 킥오프 회의록

## v3 — 가격 전환: 구독 99,000원 → 도입 서비스 500,000원 (2026-08-09, 대표 결정)

첫 학원 대상 가격을 **월 500,000원**으로 확정. 상품 성격이 바뀐다.

- **구독이 아니라 도입·운영 서비스로 판다.** 학원관리 프로그램(월 1~1.5만원)과 비교되면 지는 싸움이라, 조교 인건비(월 100~150만원)와 비교되게 놓는다.
- 포함: **교재·기출 자료 등록 대행**(핵심), 강사별 과목·말투 세팅, 무제한 사용, 문제풀이·오답노트, 전담 지원(카톡 당일), 월간 성과 리포트
- 판매 순서: 무료 파일럿 2~4주 → 성과 리포트 제시 → 도입 제안. **가격을 먼저 말하지 않는다.**
- 원가는 그대로(고정비 6.3만원 + LLM 8천원/학원) → 마진 43만원. **관건은 투입 시간**이라 계약서에 자료 등록 건수·대응 횟수 상한을 명시할 것.

### 이 가격에서 반드시 선행돼야 할 것
1. **Supabase Pro** — 무료 플랜은 백업이 없다. 50만원 받는 서비스의 데이터가 백업 없이 도는 건 불가
2. **마이그레이션 실행** — 문제풀이·오답노트가 코드만 있고 꺼져 있음 (`supabase/migrations/20260806000000_quiz_and_plan.sql`)
3. **LLM 프로바이더 확정** — Claude로 두면 원가 6만원, Gemini Flash면 8천원. 유료 전환 전 결정
4. ~~학생 계정 잠김 대응~~ → 강사가 임시 비밀번호를 발급하는 기능으로 해결 (`POST /api/students/reset-password`)

## v2 — 시장 리서치 반영 (같은 날)

국내(콴다·클래스팅·클라썸·채널톡·김과외·숨고·학원 SaaS) + 글로벌 RAG 지식봇(Khanmigo·Flint·CustomGPT·Chatbase 등) 조사 결과:

- **학생 과금 기각 확정** — 콴다(월 18,500원)도 수백만 MAU + 광고 병행이라야 성립. 소규모는 전부 사업자 과금 (채널톡·학원 SaaS·숨고 동일 패턴)
- **99,000원/월 시장가 검증** — CustomGPT $99 ↔ Chatbase $40 사이. 학원 SaaS(1~1.5만원)와 차별화하려면 "관리 도구"가 아니라 **"강사 질문 응대 시간 절약"**(채널톡 논리)으로 포지셔닝
- **무료 경계 표준 확인** — 봇(강사) 수 + 메시지 수 + 자료 제한. 기존 결정(자료 10건·일 질문 50건·OCR pro)과 일치 — 유지
- **49,000원 하위 플랜**: 코드에 안 넣음. plan enum은 free/pro 유지, 소형 학원 협상 카드로 오프라인 운영 (수동 결제라 가능)
- 리서치 출처는 에이전트 조사 결과에 링크 보존 (콴다 헬프·클라썸 pricing·채널톡 블로그·Khanmigo/Flint/CustomGPT/Chatbase pricing 등)

## 안건: 월 10만원을 어떻게 버는가

### 각 역할 의견 요약

- **기획**: 학원 단위 단일 플랜 99,000원/월. 무료 경계 = 강사 1명·자료 20건·월 질문 300건. 전환 트리거 3종(사용량 리포트→가격 페이지→한도 게이트). PG 연동·학생 리포트는 컷. *반대: 학원 1곳 의존은 인질극.*
- **디자인**: 가격표는 단일 카드(3단 비교표 허세 금지), 신뢰는 마케팅 문구가 아닌 **그 계정의 실제 카운트**(자료 수·답변 수)로. 결제 결심자는 원장 — CTA는 사용 실적 화면 뒤에. *반대: 체험 14일은 시험기간 못 겪음 — 30일이 맞을 수도.*
- **개발**: `academies.plan` 한 컬럼(테넌트 과금). 게이팅은 서버 API 3곳(documents/ask/OCR)만, `lib/plan.ts`로 집중. 결제는 문의 테이블 + admin 수동 전환. 7~8파일, 난이도 하. *반대: 유료 고객 0인데 게이팅부터는 순서 역행 — pricing+문의 먼저.*
