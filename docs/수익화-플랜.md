# 수익화 플랜 — 킥오프 회의록

2026-07-30. 참석: 기획·디자인·개발 (에이전트), PM 진행. 목표: **월 10만원 매출 가능한 완성도**.

## 안건: 월 10만원을 어떻게 버는가

### 각 역할 의견 요약

- **기획**: 학원 단위 단일 플랜 99,000원/월. 무료 경계 = 강사 1명·자료 20건·월 질문 300건. 전환 트리거 3종(사용량 리포트→가격 페이지→한도 게이트). PG 연동·학생 리포트는 컷. *반대: 학원 1곳 의존은 인질극.*
- **디자인**: 가격표는 단일 카드(3단 비교표 허세 금지), 신뢰는 마케팅 문구가 아닌 **그 계정의 실제 카운트**(자료 수·답변 수)로. 결제 결심자는 원장 — CTA는 사용 실적 화면 뒤에. *반대: 체험 14일은 시험기간 못 겪음 — 30일이 맞을 수도.*
- **개발**: `academies.plan` 한 컬럼(테넌트 과금). 게이팅은 서버 API 3곳(documents/ask/OCR)만, `lib/plan.ts`로 집중. 결제는 문의 테이블 + admin 수동 전환. 7~8파일, 난이도 하. *반대: 유료 고객 0인데 게이팅부터는 순서 역행 — pricing+문의 먼저.*
